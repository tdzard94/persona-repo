Documentation

URL Scheme
persona://

Complete reference for every persona:// command — what it does, its parameters, and ready-to-copy examples. Trigger from Shortcuts, Safari, or a Mac terminal. The app must be installed and running (foreground or background).

General format
persona://<action>?key1=value1&key2=value2
BooleansUse true/false or 1/0.
Repeatable paramsSame key multiple times for lists: &bundleId=com.a&bundleId=com.b
URL encodingSpecial characters must be encoded (@ → %40, space → %20). The app decodes automatically, including double-encoding from devicectl.
AsyncActions run in the background — results appear as alerts inside the app; nothing is returned over the URL.
Commands
persona://proxy-enable persona://proxy-disable persona://rotate-proxy persona://reset-data persona://backup-reset persona://backup persona://restore persona://login-itunes persona://itunes-status persona://logout-itunes persona://identity persona://config persona://general persona://proxy persona://rrs persona://open-settings

Data Management

Reset / backup + reset app data
persona://reset-data8 params
Reset data of the apps ticked in App Targeting, or of specific bundle IDs. Optionally applies a new device identity (hardware / firmware / region); omitted keys keep the current selection.
Parameters
KeyTypeDescription
bundleIdlistBundle IDs to reset — repeat for multiple apps. Omit = use the ticked list in the app
hardwarestringDevice model, e.g. iPhone 14 Pro or identifier iPhone15,2 (optional)
firmwarestringiOS version, e.g. 17.4.1 (optional)
countrystringRegion set — applied only if at least one key is present. Defaults: United States / US / 37.09, -95.71 / America/New_York
countryCodestring
latfloat
lonfloat
timezonestring
Examples
persona://reset-data
persona://reset-data?bundleId=com.zalo.text&bundleId=com.facebook.Facebook
persona://reset-data?bundleId=com.instagram.app&hardware=iPhone15,2&firmware=18.1&countryCode=VN&timezone=Asia%2FHo_Chi_Minh

Create a backup first, then reset data. Same parameters as reset-data, plus name and comment for the backup.
Parameters
KeyTypeDescription

hardware / firmware / region…—Same parameter groups as reset-data
Examples

How to Trigger

Shortcuts · Safari · Terminal (Mac)
iOS Shortcuts Create a shortcut → add an Open URL action → paste the command. 
persona://proxy-enable
Safari (on device) Type the command directly into the address bar — the app opens and handles it. 
persona://rotate-proxy?save=false
Terminal (Mac, devicectl) Cold launch with a payload — kill the old process first, devicectl does not restart a running app. 
xcrun devicectl device process launch \
  --device <UDID> \
  --payload-url "persona://backup?name=Test" \
  com.0x17.persona
